# ☁️ Cloud Resource & Task Scheduling Simulator

## Overview
A computational simulation modeling task scheduling and resource allocation across virtualized cloud computing nodes. Developed in a Linux (WSL Ubuntu) environment to study scheduling efficiency, workload distribution, and system throughput under simulated task queues.

## Project Structure
* **`scheduler.py`**: Core simulation engine implementing task queuing, node resource allocation logic, and scheduling policy execution.

## Methodology & Concepts
* **Resource Allocation:** Models CPU/memory capacity constraints across virtual compute nodes.
* **Scheduling Logic:** Evaluates task execution ordering, waiting times, and resource utilization metrics.

## How to Run
```bash
python3 scheduler.py
```

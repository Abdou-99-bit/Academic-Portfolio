# ☁️ Research and Advanced Computational Projects

## Overview
This directory houses advanced computational simulations, distributed systems prototypes, robotics control frameworks, and network optimization models.

## Featured Projects
* **`cloud_simulator`:** Discrete-event simulation of cloud infrastructure, virtual machine scheduling policies, and dynamic resource allocation.
* **`distributed_matrix_cluster`:** Parallel and distributed matrix computation framework analyzing communication overhead, workload partitioning, and speedup across worker nodes.
* **`hri_robotics`:** Human–Robot Interaction (HRI) module focusing on intelligent robotic behavior, control logic, and interactive task execution.
* **`traffic_optimization`:** Graph-based mathematical modeling and algorithmic optimization of urban traffic networks to minimize congestion and travel latency.

## Core Research Domains
* Distributed & Parallel Computing, Discrete-Event Simulation, Intelligent Robotics, Graph & Network Optimization.

## Running the Projects
Navigate into any individual project subfolder (`cd <project_name>`) and execute the main Python entry script (e.g., `python3 scheduler.py` or `python3 main.py`).

# 🚦 Traffic Network Modeling & Flow Optimization

## Overview
A mathematical modeling and algorithmic simulation tool for analyzing and optimizing vehicle flow across urban road networks. Implemented in Python within a Linux (WSL Ubuntu) environment to evaluate routing strategies and congestion reduction.

## Project Structure
* **`traffic_engine.py`**: Core simulation and optimization engine modeling network topology, traffic flow dynamics, and routing/signal optimization algorithms.

## Methodology & Concepts
* **Graph-Based Network Modeling:** Represents intersections and road segments as weighted graphs with capacity and travel-time constraints.
* **Flow Optimization:** Applies algorithmic routing and congestion-minimization heuristics to improve overall network efficiency.

## How to Run
```bash
python3 traffic_engine.py
```

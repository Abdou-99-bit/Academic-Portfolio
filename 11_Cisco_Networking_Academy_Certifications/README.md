# 🌍 Cisco Networking Academy Certifications

## Overview
This directory documents completed coursework, network configuration labs, and verified credentials from the Cisco Networking Academy.

## Key Areas Covered
* **Networking Fundamentals:** OSI/TCP-IP models, IPv4/IPv6 subnetting, routing, and switching protocols.
* **Cybersecurity Principles:** Network defense, access control lists (ACLs), threat mitigation, and secure infrastructure design.

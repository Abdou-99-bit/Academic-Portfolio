# 💻 Systems Programming and Algorithms

## Overview
This directory contains low-level systems programming exercises, custom data structure implementations, and algorithmic problem-solving completed through intensive peer-to-peer training (School 21).

## Key Topics & Implementations
* **C Programming & Memory Management:** Manual heap/stack allocation, pointer arithmetic, and leak-free memory handling.
* **Data Structures & Algorithms:** Custom implementations of linked lists, trees, sorting algorithms, and string manipulation libraries.
* **Unix/Linux Environment:** Shell scripting, process management, compilation workflows (`Makefile`), and Git version control.

## Technology Stack
* C (C99/C11), GNU Make, Linux/Unix CLI, Git.

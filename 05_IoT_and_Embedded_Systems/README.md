# 🌱 IoT and Embedded Systems

## Overview
This directory highlights embedded systems engineering, microcontroller programming, and automated sensor-driven monitoring.

## Featured Project: Smart Greenhouse with ESP32
* **Hardware & Sensors:** Real-time acquisition of temperature, humidity, and soil moisture telemetry using an ESP32 microcontroller.
* **Communication Protocol:** Lightweight publish/subscribe telemetry transmission via MQTT.
* **Automated Control:** Closed-loop local actuation rules for maintaining optimal environmental thresholds.

## Technology Stack
* ESP32, Arduino C++, MQTT Protocol, Embedded Sensors.
